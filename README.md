# Caesar-Cipher
Python code for encoding and decoding messages

# This program:
# 1) Takes a message and a shift amount(#) as 2 inputs and shifts each letter of the message forwards in the alphabet by the shift amount and prints the encrypted text.
# 2) Takes an encrypted message and a shift amount(#) as 2 inputs and shifts each letter of the message *backwards* in the alphabet by the shift amount and print the decrypted text.
